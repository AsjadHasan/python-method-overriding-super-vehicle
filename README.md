# python-method-overriding-super-vehicle
A Python OOP project demonstrating inheritance, method overriding, and the use of super() to call parent class methods while customizing behavior in a child class.
<br>
Topics Covered:
<br>

1. Object-Oriented Programming (OOP)
2. Classes and Objects
3. Inheritance
4. Parent and Child Classes
5. Constructor (__init__)
6. Instance Attributes
7. Instance Methods
8. Method Overriding
9. super() Function
10. Default Arguments
11. Code Reusability (DRY Principle)
12. Return Statements
